Submeter Billing Tracker

Splits electricity bills between tenants and keeps the records on GitHub.

problem
Every month I split shared electricity bills by hand and typed a separate WhatsApp message for each tenant.
approach
One static page, it splits the bill by each tenant's meter usage, carries unpaid balances forward, and writes the messages.
data
Records live in a plain text file in a private GitHub repo, reached with a token limited to that one repo.
trade-off
No server, so you enter the token once on each device.
